Talk to us before you install

meerkatPOS connects to an ERPNext server set up for your business, that part isn't something you can configure on your own. Email support@meerkatpos.me first so we can get your server ready, then come back here to download and follow the setup steps below.

Each machine needs MariaDB Server installed first

Both the Hub and every Till keep a local MariaDB Server for their offline cache, install and start it before running the meerkatPOS installer: winget install MariaDB.Server on Windows, brew install mariadb on Mac, or sudo apt install mariadb-server on Linux. The setup guide below has the full field-by-field walkthrough.

Getting set up

Two roles, one install for everyone, and one email to start.

  1. 1 Contact us Get your server set up Email support@meerkatpos.me so we can set up your ERPNext server. meerkatPOS connects to it and can't be configured on your own.
  2. 2 Hub Install on one machine as the Hub This is the machine that talks to your ERPNext server. Install one per store location.
  3. 3 Till Install on every other counter as a Till Till machines connect to the Hub over your local network. No internet required for a sale to go through.
  4. 4 Hub Log in and start selling Your account details are provided by whoever set up your meerkatPOS server.
